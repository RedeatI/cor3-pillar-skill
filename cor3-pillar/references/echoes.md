# Echoes of Planetside

游戏内 The Pillar 等级说明曾明确要求完成 Echoes。开始执行时核对当前账号的等级说明、News、任务记录和 MR-7 Media Reader。普通 Game Center 的 DAILY OPS 单独记录。

1. 找到 RM7-S4L2，取得 `USSDP-V1250_Rep.AD64`，按游戏内流程装载到 MR-7。一次地图搜索无结果时确认提交后再检查中转节点与剧情权限。实测有账号在 E1SCP / 南部线路推进后找到 S4L2；具体可达路径随账号而异。
2. 打开对应 News 或 Forum 条目并读游戏提示。已发现、可访问、已解锁是不同状态。实测补读 The Pit 的论坛帖后，磁盘已解锁数从 5 增至 6。另一账号从历史新闻取得 RM7-E1L5 的文件提示，下载并读完指定文件后解锁 A1。July 的联系人与档案路线可查旧攻略，并在本号验证。
3. 补完当轮能做的历史和当前章节，以任务完成反馈和碎片计数变化核实。分别记录已解锁数、已发现数、当前章节、最后核实时间和具体阻碍。兑换码不写进共享记录或公开输出。
4. 看见实际倒计时再安排续办。旧活动曾按天发布新闻；3.104.9 的开发方公告说 Code C 碎片随任务开放，取消该部分的日历等待。逐号检查剩余章节与具体冷却，不能从旧发布时间推算每个账号的固定完工天数。
