# Echoes of Planetside

游戏内 The Pillar 等级说明曾明确列了完成 Echoes。开跑时先对照当前账号的 The Pillar 说明、News、任务记录和 MR-7 Media Reader。Game Center 里的普通 `DAILY OPS` 另开一行记。

1. 在 Network Map 搜 `RM7-S4L2`（注意确认真的点了提交，再等结果），拿到 `USSDP-V1250_Rep.AD64` 后按游戏流程装进 MR-7。搜不到时查中转节点和剧情权限；有账号在推完 E1SCP / 南部线路后才找到 S4L2，具体路径因号而异。
2. 逐条看对应的 News 和 Forum 帖子里的线索。磁盘里“已发现”“可访问”“已解锁”是三种状态：有号补读完 The Pit 论坛帖后，已解锁碎片数从 5 涨到 6；另一号从历史新闻看到 `RM7-E1L5` 文件提示，下载并读完指定文件后解锁了 A1。July 的联系人与档案路线可以参考旧攻略，在当前账号里实测。
3. 每天逐号分别检查 A/B 任务和 C 任务：两支各完成至少 1 项可做任务，已经开放的旧章节当轮顺手补完。以任务完成反馈和 MR-7 碎片计数变化为准。按支记清完成章节和具体卡点，另记实读的已解锁数、已发现数和核实时间；就算遇到旧兑换码失效，照样看任务和碎片算不算进 The Pillar，兑换码仅限自用，严禁写入记录。
4. 旧活动时期曾按天发新闻；游戏 3.104.9 开发方公告说明 Code C 碎片改为随对应任务开放，取消了这部分的日历等待。现版 A/B 怎么刷新、每个号是不是仍要耗时 31 天，目前还待验证。遇到没开放的章节，先查游戏界面提示的剧情、节点权限和文件前置；只有界面真显示刷新或冷却倒计时，才按实读时间约下一轮。
