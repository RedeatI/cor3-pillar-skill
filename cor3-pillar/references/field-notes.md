# 实测摘要

下面是 2026-11-09 汇总的匿名账号阶段实测（原始账号进度和截图留在本地）。这些案例用来帮你指路排障，适用范围限于对应样本与当日版本。

| 界面看到的现象 | 实测结果 | 怎么复用与限制 |
| --- | --- | --- |
| 样本 A 的 `Porter-lite r4` 只有 12，GPU 条发黄，电源满载 | 保留 `UNO 6.651` CPU 和 `Emerald H2S9` 内存，只换 `Force Recon 13D` GPU 和 `Quartz 28-BR` 电源后升到 15，顺利打进防御 13 的 N1L1、N2L2 | 两件合计 50,830 CR 是当时价格；配装先看黄条和供电。同时换两件只能确认这套组合有效，单件各自涨了多少未拆测，换到其他配置上先重看面板 |
| 样本 B 只把 CPU 升到 `Hex Lattice 14+` 并换 `Quartz` 电源，留着 `OmniPix` GPU | Porter 依然停在 12 | 这款软件吃重 GPU，单升 CPU 和电源未必涨 Power，买之前先盯准资源面板发黄的那一项 |
| 样本 A 同时装着 `Seeker-IV` 和 `Porter` | Porter 从 12 掉到 7，卸掉 Seeker 就回到 12；所测中转搜索还是没工具可用 | 并装软件会抢资源；已有软件不用重复买，单次中转没搜出结果也先当作路线样本，后续另测 Seeker 用途 |
| S4WCP 第一次点完跳回界面，没给出成败提示 | 后来再试拿到访问权限，地图搜出 S4L2，下了活动磁盘并在读取器解锁 1 个碎片 | 没给原因时先重查状态再安全重试；拿到新权限记得回扫地图；这次只验证了 S4WCP 通向 S4L2 解锁 1 个碎片的路径，其余前置和碎片另行核实 |
| 佣兵卡片里有同名隐藏按钮，点完签约没反应 | 走完引导、选中当前卡片里可见的按钮后成功打开合同并派出 Matrix | 结合所属卡片和可见状态点按钮，跳过排在前面的同名隐藏节点 |
| Matrix 拿 `TX-71` 合同：报价 8000、预付 3200、佣金写 400 | 成功后实际付尾款 4800，从信箱领进库存；总实付正好 8000，没见额外再扣 400 佣金 | 出发、返回结算、信箱领货分开看余额和状态；总实付以实际扣款之和为准（界面写的 400 佣金含在报价里） |
| 远征回来后 Aurana 回复按钮变灰，点多次发不出去 | 在没有未完成计时动作时刷新页面，重进后同一条回复直接发出 | 盯着聊天记录看新消息有没有出来；仅验证一次恢复，变灰原因未知 |
| 列表刷新后沿用旧序号；删游戏文件后任务依然显示没完成 | 实际接到的单子跟想接的不是同一个；另一操作补点确认框后才成功领奖 | 列表一刷就按任务名和文件重找卡片，弹窗再核对一遍；删文件点完确认框看到文件真没了才算完，卡住先查确认框，别全怪服务器慢 |
| 安装软件提示先关机，但顶部 `POWER ON` 标题不变 | 去点真正的电源开关，以“系统已关闭/启动”通知和安装结果为准 | 开关机状态只看操作电源控件后弹出的“系统已关闭/启动”通知和安装结果，忽略静态 `POWER ON` 标题 |
| 图纸已经解密，Aurana 这边却没后续对话 | 打开图纸 `INFO`，在游戏内浏览器访问本号 metadata 里的地址，再回去汇报就触发了后续 | 看完图和去游戏内浏览器访问存储地址是两步，缺一步就会卡住；先确认游戏内连接正常 |
| 远征合同里的付款按钮是灰的 | 查出需要先过完引导，在可见合同里勾上风险条款，并保证余额够预付款和尾款 | 勾选框打勾后再看付款按钮；派出成功与否看余额扣款和远征状态 |
| 委托已经显示可完成，点卡片详情反复打不开 | 把盖在市场前面的系统日志 / DAILY OPS / Game Center 面板收起，按文件和发行人找卡，走 Info → Complete 顺利领了两笔奖 | 复用了先收遮挡面板的顺序；具体是哪一个面板引起遮挡未单独隔离测 |
| 买完 CPU 安装，一直弹提示要求先关机 | 单点一次关机并等新增关机通知，打开替换列表等界面稳住再应用新件；确认主机型号后开机并重读 Power | 一次实测换装后 Porter 8 → 12；按当前负载再测一次强度 |
| 定时任务显示 ACTIVE，但提示词和路径变乱码 | 修回完整提示词后用 UTF-8 重读一遍确认 | 看到 ACTIVE 后仍要重读一遍提示词和路径确认没乱码；改调度走宿主官方接口，不动原始配置文件 |

后台渲染的边界见 [后台控制](background-control.md)。新发现和反例继续写进你自己的本地共享库；这里记的历史价格、路线和 Power 仅供对照，动手前以当前账号游戏界面为准。
