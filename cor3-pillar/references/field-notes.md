# 实测摘要

以下为 2026-11-09 汇总的阶段性游戏实测，使用匿名样本；原始账号进度和截图留在本地。它们提供排查方向，未作跨版本普遍性验证，也不代表从零到 The Pillar 的完整通关证明。

| 现象 | 实际结果 | 可复用做法与限制 |
| --- | --- | --- |
| 样本 A 的 Porter-lite r4 为 12，GPU 条黄色，电源已满载 | 保持 UNO 6.651 CPU 与 Emerald H2S9 内存，更换 Force Recon 13D GPU 和 Quartz 28-BR 电源后为 15；进入防御 13 的 N1L1、N2L2 | 两件合计 50,830 CR 是当时价格；先看资源与供电。同次更换两件不能拆分各自贡献，不保证其他配置同效 |
| 样本 B 只升级 Hex Lattice 14+ CPU 和 Quartz 电源，保留 OmniPix GPU | Porter 仍为 12 | “更强 CPU”不等于此软件必定提强度，购置前确认实际瓶颈 |
| 样本 A 同装 Seeker-IV 与 Porter | Porter 从 12 降至 7，卸载 Seeker 恢复 12；所测中转搜索仍无工具 | 并装可争用资源；不重复购买已拥有软件，不能据此断言 Seeker 完全无用 |
| S4WCP 首次操作后界面返回，没有明确成败反馈 | 后来重试取得访问，之后地图发现 S4L2，下载活动磁盘并在读取器显示 1 个碎片解锁 | 无原因时先核实再安全重试；新权限后查地图；没有证明 S4WCP 是唯一前置，也不是活动全部完成 |
| 佣兵卡有同名隐藏按钮，签约没有推进 | 完成引导、选择可见卡片按钮后成功打开合同并派出 Matrix | 以卡片上下文和可见状态定位，不能只选第一个同名元素 |
| Matrix 获取 TX-71 合同：报价 8000、预付 3200、佣金显示 400 | 成功后实际付尾款 4800，并从信箱移入库存；观察到总实付 8000，未见另扣佣金 | 出发、成功、结算和领取分别核验；不能把佣金文字额外加进已扣款 |
| 远征后的 Aurana 回复变灰，多次点击没有发送 | 在无未完成计时动作时刷新，重新进入后同一回复成功 | 看聊天记录是否新增消息；只验证一次恢复，禁用原因未知 |
| 任务列表刷新后沿用旧序号；删除游戏文件后任务仍未完成 | 实际接到目标与原意不同；另一操作补上确认后才领奖 | 刷新后重新锁定完整任务，确认界面再核对；首击不是完成证明，不能全归因于服务器慢 |
| 软件安装要求关机，但 POWER ON 标题不变 | 操作实际电源控件，以“系统已关闭/启动”通知及安装状态确认 | 静态标题不是电源状态证据 |
| 图纸已解密，Aurana 没出现后续 | 读图纸 INFO，在游戏内浏览器访问本号元数据里的地址，再汇报，已实测触发后续 | 看到图片与访问存储地址是两步；先核对游戏内连接 |
| 远征合同付款按钮灰色 | 实测应先看引导、可见合同内的风险条款勾选，以及预付款和尾款资金 | 勾选后再观察按钮；实际派出以余额和任务状态确认 |
| 委托可完成，详情反复打不开 | 收起盖在市场前的日常面板后，按文件和发行人定位卡片，走 Info → Complete，已领取两笔奖励 | 复用了有效操作顺序，单独导致失败的面板未隔离 |
| CPU 已购，安装反复提示先关机 | 单次关机并确认新增通知，打开替换列表待稳定，再应用已购配件。确认主机型号后开机并重读 Power | 一次实测换装后 Porter 8 → 12；按当前负载验证强度 |
| 定时任务 ACTIVE，但提示与路径曾变成乱码 | 修复完整提示后用 UTF-8 重读确认 | 状态正常不证明执行内容正确；不直接写原始调度配置 |

后台渲染的具体适用范围见 [后台控制](background-control.md)。新发现和反例继续进入使用者自己的共享库；这里的历史价格、路径条件和强度不能替代当前账号界面。
